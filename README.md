# Haushaltsbuch

Persönliche Finanz-App als Android-APK.

- `web/index.html` – die App selbst (dieselbe Datei wie die Claude-Version)
- `android/` – kleine Android-Hülle, die die App anzeigt; Daten bleiben auf dem Handy
- `.github/workflows/build-apk.yml` – baut bei jedem Push die APK und stellt sie unter **Releases › neueste** bereit

## Installieren
1. Auf GitHub unter **Releases** die Datei `Haushaltsbuch.apk` aufs Handy laden.
2. Öffnen und Installation aus dieser Quelle erlauben.
3. In der App unter **Einstellungen › Backup laden** das Backup einspielen.

Updates: neue APK einfach drüber installieren, die Daten bleiben erhalten.
